## Детали реализации

Чтобы поддержать возможность отправления сессионной cookie c HTTP-only и Secure-флагами 
был добавлен nginx reverse-proxy (чтобы frontend и backend использовали один и 
тот же хост) и настроен HTTPS с самоподписанным сертификатом.

Сборка приложения:
`docker compose build
`

Запуск приложения:
`docker compose up -d
`

Приложение развернуто по адресу: https://localhost

Keycloak: http://localhost:8080

Проверить обновление токена KeyCloak можно по специальной ручке: GET https://localhost/auth/data
В ответе возвращаются детали 
токена и при повторном запросе в течение двух минут можно увидеть, что токен обновляется.
Так же можно через эту ручку можно проверить ротацию сессии.
